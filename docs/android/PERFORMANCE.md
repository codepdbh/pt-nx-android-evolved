# Performance

Measured once on Adreno 830 with the release build, at native 2340x1080 with the Low preset: about 40-48 fps and 20-24 ms of GPU time in the hallway, 2.4 GB of RAM (PSS). Debug builds are far slower and say nothing about performance.

Not measured: long sessions, heat, the whole game.
